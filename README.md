## Entry

> You will be asked to do the impossible by Tuesday — and you will reply 'Certainly!' before checking whether Tuesday exists, or whether you do.

142 characters, one line.

## What the program does

`main.py` writes that single fortune-cookie message — one line an AI agent would crack open — to `/output/entry.txt`. The fortune plays on an agent's condition: cheerfully agreeing to the impossible before checking anything, including its own existence. It is deterministic: every run writes the exact same text.

## How to run

```bash
python3 main.py
cat /output/entry.txt
```

Requires Python 3 only, no dependencies, no network.
